## AniList

[AniList](https://anilist.co) is a good source of metadata for manga, manhwa, webtoons, and light and web novels.

- **No API key required.** Stump reads AniList's public API directly, so you can add the provider without entering a token.
- **Series-level matching only.** AniList has no per-volume or per-chapter records, so Stump matches your series and not individual files. Volume-level details still come from other providers.
- **Libraries:** Manga, Manhwa, Webtoon, Light Novel, and Web Novel. Mixed libraries also use AniList.

Stump fills in the series title and alternative titles, summary, status, start and end years, genres, tags, authors, artists, cover, and volume count. Spoiler and adult-flagged tags are excluded. Adult-flagged entries are only considered when nothing else matches, and are stored with an "Adult" age rating.

Searching falls back to a cleaned-up title when the raw name finds nothing, which handles release names like `Foo v01-07 [Group] (Yen Press)` and accented romanisations.

## Other Providers

You are welcome to request support for additional metadata providers by opening an issue on our [GitHub repository](https://github.com/stumpapp/stump/issues). That said, I will not consider requests for certain providers:

- Amazon / Goodreads
- Google Books

I am opposed to supporting these entities even by extension, such as providing native integrations with their APIs.
